画像ツール一覧

はじめに

このページでは、様々な画像処理ツールを提供しています。 画像の角丸め、輪郭抽出、重ね合わせ、色変換など、画像編集に必要な機能を簡単に利用できます。 各ツールは専用ページで詳細な機能を提供しています。 すべての処理はブラウザ上で実行されます。 画像をアップロードしても外部への送信は行われません。

画像編集ツール

画像形状編集

画像の形状を編集するツールです。

画像の角丸め＆リサイズ

丸みを帯びたアイコンの作成ができます。透過背景にも対応しています。

画像の角丸めツールを使用する

画像の輪郭抽出

画像から輪郭を抽出し、線画として保存できます。感度や線の太さを調整可能です。

画像の輪郭抽出ツールを使用する

画像合成・変換

複数の画像を合成したり、色を変換したりするツールです。

画像の重ね合わせ

2つの画像を重ね合わせて1つの画像として保存できます。位置や透明度を調整可能です。

画像の重ね合わせツールを使用する

画像の色変換

画像内の特定の色を別の色に変換できます。透明度や許容範囲を調整可能です。

画像の色変換ツールを使用する
