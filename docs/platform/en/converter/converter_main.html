iroiro(Various) Tools List

Introduction

This page provides various conversion tools. You can easily use frequently needed conversion functions such as text encoding/decoding and hash generation. Each tool offers detailed functionality on its dedicated page.

String Conversion

Encode/Decode

Tools for encoding and decoding text and binary data.

Base64 Encode/Decode

Encode text or binary data into Base64 format, or decode from Base64.

Use Base64 Encode/Decode Tool

Hash Generation

Tools for generating hash values from text.

MD5 Hash Generation

Generate MD5 hash values from text. Used for data integrity checks and other purposes.

Use MD5 Hash Generation Tool

SHA Hash Generation

Generate SHA-1, SHA-256, and SHA-512 hash values from text. These are more secure hash algorithms.

Use SHA Hash Generation Tool
