sequenceDiagram
    participant Alice as Alice (Sender)
    participant Bob as Bob (Receiver)
    participant KeyGen as Key Generator

    Note over KeyGen,Bob: Bob generates public and private keys

    KeyGen-->>Bob: Public key (Bob_PK)\nPrivate key (Bob_SK)

    Bob->>Alice: Distribute Bob_PK to Alice (public)

    Alice->>Alice: Create plaintext
    Alice->>Alice: Encrypt plaintext using Bob_PK

    Alice->>Bob: Send ciphertext

    Bob->>Bob: Receive ciphertext
    Bob->>Bob: Decrypt ciphertext using Bob_SK

    Bob->>Bob: Obtain plaintext (original message)
