    Note right of ClientSSH: Source: localhost:3000<br>Destination: localhost:(random port B)

    ClientSSH -->> SSHServer: ⑥ Forward response through tunnel
    Note over SSHServer, ClientSSH: Transferred within encrypted SSH session (port 22)

    deactivate ClientSSH
    SSHServer -->> ExternalUser: ⑦ Return response to external user
