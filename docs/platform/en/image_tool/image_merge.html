Image Overlay & Download Tool

How to Use
  1. Upload a base image (file selection or drag & drop)
  2. Upload an overlay image (file selection or drag & drop)
  3. Adjust the position and size of the overlay image if needed
  4. Adjust transparency if needed
  5. Check the preview
  6. Download in your preferred format
    • For transparent background: PNG (Transparent)
    • For background color: PNG (With background color) or JPEG (With background color)
  7. No images are uploaded to any server. All processing is done in your browser.
