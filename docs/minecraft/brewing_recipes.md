# 醸造台レシピ一覧（Java版）

本ページは Java 版マインクラフトの「醸造台」で作れるポーション（錬金）レシピの早見表です。`template/guide/guide_sample.md` の構成方針に倣い、要点を簡潔にまとめています。

---

## 基本の流れ
- 燃料: ブレイズパウダー（醸造台左）
- 素体: 水入り瓶（3 本まで同時醸造可）
- 下準備: ネザーウォート → 不完全なポーション（奇妙なポーション, Awkward）を作成
- 仕上げ: 対象素材を投入して目的のポーションを醸造
- 強化/延長: グロウストーンダスト（強化）/ レッドストーン（延長）
- 投擲化: 火薬（スプラッシュ化）
- 残留化: ドラゴンの息（リリンガー化）

補足:
- 発酵したクモの目は「堕落（変質）」系。既存ポーションを別系統へ変換します。
- 厚い/むらさき/奇妙でない素体（尋常/濁った等）は Java 現行では用途が限定/なしの場合があります。

---

## ベースポーション
- 奇妙なポーション（Awkward）: 水入り瓶 + ネザーウォート
- むらさきのポーション（Mundane）: 水入り瓶 + 砂糖/グリセリンメロン/マグマクリーム 等（用途ほぼなし）
- 濃厚なポーション（Thick）: 水入り瓶 + グロウストーンダスト（用途ほぼなし）
- 水の瓶: 一部の派生や堕落用素材の中間で使用

## 代表レシピ一覧

記法:「素材 → 効果（基本効果時間/強度）」。延長/強化は後述。

### 攻撃/ユーティリティ
- 砂糖 → 俊敏のポーション（移動速度上昇）8:00 / 3:00（強化で1:30, 延長で8:00）
- ウサギの足 → 跳躍のポーション（跳躍力上昇）3:00（延長 8:00 / 強化 1:30）
- 火打石と打ち金…ではなく マグマクリーム → 耐火のポーション 3:00（延長 8:00）
- フグ → 水中呼吸のポーション 3:00（延長 8:00）
- スイレンの葉ではなく カメの甲羅（カメの甲羅作成: 子ガメの抜け殻×5）→ タートルマスター 0:20（強さ I: 耐性 + 鈍化 / 強さ II: 0:20、延長 0:40）
- ファントムの皮膜 → 低速落下のポーション 1:30（延長 4:00）
- ブレイズパウダー → 力のポーション 3:00（強化 1:30 / 延長 8:00）
- グリセリンメロン（輝くスイカの薄切り）→ 治癒のポーション（即時回復）
- クモの目（発酵なし）単独は使用不可（ベースは Awkward）

### 防御/回復/状態異常
- ガストの涙 → 再生のポーション 0:45（延長 1:30 / 強化 0:22）
- 発酵したクモの目 → 毒のポーション 0:45（延長 1:30 / 強化 0:22）
- 発酵したクモの目（堕落）
  - 俊敏 → 鈍化
  - 跳躍 → 鈍化
  - 治癒 → 負傷
  - 再生 → 毒
  - 力 → 弱化
  - 耐火 → 変化なし（不可）
  - 水中呼吸 → 変化なし（不可）
  - 低速落下 → 変化なし（不可）
- クモの目 + 発酵（砂糖 + 茶キノコ + クモの目で作成）自体は素材、直接のポーションではありません
- 通常の弱化は「奇妙なポーション + 発酵したクモの目」でも作成可

### 特殊
- 発酵したクモの目（単独, Awkward ベース）→ 弱化のポーション 1:30（延長 4:00）
- グロウストーンダスト（Awkward ベース）→ 濃厚なポーション（用途ほぼなし）
- レッドストーン（Awkward ベース）→ 効果なし（延長は既存効果への後処理）

---

## 強化・延長・投擲・残留の後処理
- 強化: グロウストーンダスト → 効果時間短縮/強度上昇（治癒/負傷は回復量/ダメージ量上昇）
- 延長: レッドストーン → 効果時間延長（強度は据え置き）
- スプラッシュ化: 火薬 → 投げて範囲効果（持続は約 3/4 に）
- リリンガー化: ドラゴンの息 → 地面に残留する霧（スプラッシュが前提）

処理順の注意:
1) 目的のポーション完成 → 2) 強化 or 延長 → 3) スプラッシュ → 4) 残留

## クイックガイド（ベース別）

### Awkward（奇妙なポーション）ベース

| ポーション | 素材 | 基本 | 強化 | 延長 |
|---|---|---|---|---|
| 俊敏 | 砂糖 | 3:00 | 1:30（II） | 8:00 |
| 跳躍 | ウサギの足 | 3:00 | 1:30（II） | 8:00 |
| 耐火 | マグマクリーム | 3:00 | — | 8:00 |
| 水中呼吸 | フグ | 3:00 | — | 8:00 |
| 力 | ブレイズパウダー | 3:00 | 1:30（II） | 8:00 |
| 再生 | ガストの涙 | 0:45 | 0:22（II） | 1:30 |
| 治癒（即時） | グリセリンメロン | 即時 | 即時（II） | — |
| 低速落下 | ファントムの皮膜 | 1:30 | — | 4:00 |
| タートルマスター | カメの甲羅 | 0:20（I） | 0:20（II） | 0:40（I） |
| 毒 | 発酵したクモの目 | 0:45 | 0:22（II） | 1:30 |

### 水の瓶（ネザーウォート不要）ベース

| ポーション | 素材 | 基本 | 強化 | 延長 |
|---|---|---|---|---|
| 弱化 | 発酵したクモの目 | 1:30 | — | 4:00 |

### むらさき（Mundane）/ 濃厚（Thick）
- 用途はほぼありません。通常のレシピでは使用しません。

### 堕落（変換）クイック参照
- 俊敏 → 鈍化
- 跳躍 → 鈍化
- 治癒 → 負傷（即時）
- 再生 → 毒
- 力 → 弱化
- 耐火 / 水中呼吸 / 低速落下 → 変化なし（不可）

注: スプラッシュ化/残留化後は効果時間が短縮されます（スプラッシュ ≒ 0.75x、残留はさらに減少）。

## よくある質問（FAQ）
- Q. ネザーウォートを忘れたら？
  - A. 多くの目的ポーションは Awkward が必要。まず Awkward を作ってから素材を投入してください。
- Q. どの順で後処理すべき？
  - A. 強化/延長 → スプラッシュ → 残留 の順。スプラッシュ化後に強化/延長はできません。
- Q. 統合版と違いは？
  - A. 一部レシピや時間、効果範囲に差異があります。本表は Java 版基準です。

## クラフト補足（素材の作り方）
- グリセリンメロン: スイカの薄切り + 金塊 ×8
- 発酵したクモの目: クモの目 + 砂糖 + 茶色のキノコ
- カメの甲羅: 子ガメの抜け殻 ×5 で作成
- ドラゴンの息: エンドでエンダードラゴンのブレスの雲（紫の霧）にガラス瓶を使用して採取（瓶多め推奨、被弾に注意）
