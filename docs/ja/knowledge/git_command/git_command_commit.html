Gitコミット関連のコマンド解説

コミット関連のコマンド

git commit - 変更をリポジトリにコミット

ステージングエリアの変更をリポジトリに記録します。

オプション 説明
-m <メッセージ> コミットメッセージを指定
-a, --all 追跡中のファイルをすべて自動的にステージングしてからコミット
--amend 直前のコミットを修正
--no-edit amendと共に使用し、前回のコミットメッセージを再利用

例:

git commit -m "Add new feature" - メッセージ付きでコミット
git commit -am "Fix bugs" - 追跡中のファイルを自動的にステージングしてコミット
git commit --amend - 直前のコミットを修正（エディタが開く）
git commit --amend -m "Updated commit message" - 直前のコミットメッセージを変更
git commit --amend --no-edit - 直前のコミットに変更を追加（メッセージは変更しない）
