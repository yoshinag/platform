将棋盤ダイアグラム生成

SFEN と注釈から将棋の局面図を描く Mermaid 外部ダイアグラムプラグイン（shogiboard 記法）のデモです。

使用方法
  1. shogiboard で始め、sfen: 行に局面を一行で記述します（初形は省略可）。
  2. highlight:（マス強調）、arrow:（矢印）、label:（注釈）、flip:（後手視点）、caption:（図題）を追加できます。
  3. マス目は「筋(1-9)+段(a-i)」で表記します（例: 7f = 7 筋 f 段 = 7六）。
  4. PNG / SVG でダウンロードできます。処理はすべてブラウザ上で完結します。
shogiboard
  sfen: lnsgkgsnl/1r5b1/ppppppppp/9/9/2P6/PP1PPPPPP/1B5R1/LNSGKGSNL w - 2
  highlight: 7f
  arrow: 7g -> 7f
  label: 7f "▲7六歩"
  caption: "▲7六歩まで"

記法を入力すると、ここに盤面が表示されます。

記法リファレンス
キー意味例
sfen局面（SFEN 一行）。大文字=先手、小文字=後手、+=成駒sfen: lnsgkgsnl/... b - 1
highlightマス強調（空白区切りで複数可）highlight: 7f 2f
arrow矢印（行ごとに 1 本）arrow: 7g -> 7f
labelマスへの注釈label: 7f "▲7六歩"
flip後手視点に反転flip: true
caption図のキャプションcaption: "図1"

Mermaid v10 以降の registerExternalDiagrams() で登録された外部ダイアグラムです。プラグイン本体は js/mermaid_shogiboard.js、他の Mermaid 図と同居できます。
