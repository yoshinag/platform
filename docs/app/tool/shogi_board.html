将棋盤ダイアグラム生成

盤面をクリック操作すると shogiboard 記法（Mermaid 外部ダイアグラム）が自動生成されます。テキストを直接編集しても盤に反映される双方向エディタです。

使い方
  1. 駒を置く: 「手番側（先手 / 後手）」と駒を選び、盤のマスをクリック。空を選んでクリックすると駒を消せます。
  2. ハイライト: マスをクリックで強調の ON / OFF。
  3. 矢印: 始点 → 終点の順にマスをクリック。
  4. ラベル: マスをクリックして注釈文字を入力（空で削除）。
  5. 右下のテキストが shogiboard 記法です。直接編集しても盤へ反映されます。PNG / SVG でダウンロード可。処理はすべてブラウザ上で完結します。
モード
手番側
持駒を編集

盤を操作するか記法を入力すると、ここに局面が表示されます。

記法リファレンス
キー意味例
sfen局面（SFEN 一行）。大文字=先手、小文字=後手、+=成駒sfen: lnsgkgsnl/... b - 1
highlightマス強調（空白区切りで複数可）highlight: 7f 2f
arrow矢印（行ごとに 1 本）arrow: 7g -> 7f
labelマスへの注釈label: 7f "▲7六歩"
flip後手視点に反転flip: true
caption図のキャプションcaption: "図1"

Mermaid v10 以降の registerExternalDiagrams() で登録された外部ダイアグラムです。プラグイン本体は js/mermaid_shogiboard.js、他の Mermaid 図と同居できます。
