iPhone / iPad アイコンサイズ生成ツール

使用方法
  1. 1024×1024 程度の正方形画像をアップロードしてください（ファイル選択またはドラッグ＆ドロップ）。
  2. iPhone / iPad / App Store の各サイズの PNG が自動生成されます。
  3. 個別ダウンロードのほか、Xcode の Assets.xcassets/AppIcon.appiconset/ 構造を含む ZIP として一括ダウンロードできます（Contents.json 自動生成）。
  4. サーバーへの画像アップロードは行われず、すべての処理はブラウザ上で完結します。
