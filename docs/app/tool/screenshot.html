App Store スクリーンショットサイズ調整ツール

使用方法
  1. iPhone / iPad のスクリーンショット画像を複数まとめてアップロードしてください（ファイル選択 / ドラッグ＆ドロップ）。
  2. 各画像の縦横比から自動的にポートレート / ランドスケープを判定し、各デバイスサイズに変換します。
  3. フィット方法（cover / contain / stretch）と、レターボックス時の背景色を選択できます。
  4. 個別にダウンロードするか、デバイスサイズごとのフォルダ構造を持つ ZIP として一括ダウンロードできます。
  5. サーバーへの画像アップロードは行われず、すべての処理はブラウザ上で完結します。

または、ここに画像をドラッグ＆ドロップしてください（複数同時可）
