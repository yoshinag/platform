App Tools & Knowledge

アプリ開発で使える小さなツール群と運用ノート集。すべてブラウザ上で動作し、サーバーにファイルは送信されません。

ツール

  • iPhone / iPad アイコンサイズ生成 画像を一枚アップロードすると、Apple HIG に準拠した各サイズの PNG を一括生成します。
  • App Store スクリーンショットサイズ調整 複数のスクリーンショット画像を、App Store が要求する iPhone / iPad の各サイズに変換します。

ナレッジ

  • Android Studio で Swift / iOS アプリを開発するノート Xcode を直接使わず、Android Studio + CLI（xcodebuild / simctl / idb）で iOS アプリを開発する運用まとめ。pre-commit / SwiftLint / シミュレータ自動化の TIPS を含む。
  • iOS アプリで Google AdMob UMP（同意管理）を統合する GDPR / 米国州法の同意要件を満たすための UMP SDK 導入・コード実装・AdMob コンソール作業のまとめ。プライバシーポリシー URL の置き場所、SDK API リネーム、子ども向けアプリの配慮など、ハマりどころも整理。
