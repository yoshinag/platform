FEATURES

MonoFlick ができること

iPhone を「片手オンリーで完結する PC 入力デバイス」に変える 4 つの機能。

片手フリック入力

親指 1 本で打てるよう調整された日本語フリックキーボード。

片手トラックパッド

iPhone 全面をトラックパッドにして Mac のポインタを片手で操作。タップ・ドラッグ・スクロールに対応。

PC へキー送信

入力した文字や任意のキーバインドを アプリを通じて、Mac のフォアグラウンドアプリへ即時送信。

アプリ起動ランチャー

Mac 上の任意アプリを iPhone からワンタップでフォアグラウンドに呼び出す。

MAC COMPANION

Mac コンパニオンの画面

メニューバー常駐の小さなアプリ。日々触るのはこの画面たちです。

Mac 機能ガイドを見る

屋内も屋外もシームレスに接続

  • 屋内 (Wi-Fi あり): ローカルネットワーク接続を利用した通信
  • 屋外 (Wi-Fi なし): Bluetooth Low Energy + L2CAP CoC（有料）

2 つの経路が並走し、先に確立した方が active になります。BLEは有料ですが、Wi-Fiだけでも通信に問題はありません。

解析ゼロ・広告ゼロ・サーバゼロ

  • 外部サーバへいかなる個人データも送信しません
  • 広告 ID (IDFA) や端末識別子を取得しません
  • Firebase / Sentry / Crashlytics 等のサードパーティ SDK は導入していません
  • すべての通信は iPhone ↔ あなたの Mac の 2 点間のみ（サーバレス）

Homebrew で入れる (macOS)

Homebrew Cask 経由でもインストールできます。アップデート・アンインストールも brew で完結します。

Install
brew tap yoshinag/monoflick-companion-for-macos
brew install --cask monoflick-companion
Update
brew update
brew upgrade --cask monoflick-companion
Uninstall
brew uninstall --cask monoflick-companion
brew untap yoshinag/monoflick-companion-for-macos
