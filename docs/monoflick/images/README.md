# LP 用イラスト一覧 (いらすとや)

`docs/index.html` が参照しているイラストの一覧。いずれも [いらすとや](https://www.irasutoya.com) から
ダウンロードして本ディレクトリに配置する。

## 利用規約まわり

- いらすとやの素材は商用・非商用とも利用可。**1 つの制作物につき 21 点以上の使用は有償**。
- 素材集としての再配布禁止。
- 直リンク（hotlink）禁止 — 必ずダウンロードして本リポジトリに同梱する。

本 LP の使用点数は 10 点 (上限 20 点内)。

## 必要ファイル

| ファイル名 | 用途 | いらすとや検索キーワード例 |
|---|---|---|
| `hero_one_hand.png` | ヒーロー画像。スマホを片手で操作する人物 | 「スマートフォン 片手」「フリック入力」 |

| `feature_pc_input.png` | 機能: PC へキーストローク送信 | 「スマホ パソコン 連携」「リモート操作」 |

## 推奨フォーマット

- 形式: PNG (透過背景推奨)
- 幅: 480〜800px 程度 (`<img>` 側で `max-width` 指定済み)
- ファイルサイズ: 1 点あたり 200KB 以下を目安

## 配置後の確認

ローカルで `index.html` を開き、すべてのスロットに画像が表示されることを確認する。

```sh
open docs/index.html
```
