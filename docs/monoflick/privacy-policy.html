プライバシーポリシー / Privacy Policy

最終更新: 2026-05-30 / Last updated: 2026-05-30

本ドキュメントは MonoFlick (iOS アプリおよび macOS コンパニオンアプリ) の正式なプライバシーポリシーです。日本語版を上に、英語訳を下に掲載します。

This document is the canonical privacy policy for MonoFlick (iOS and the macOS companion app). It is published in Japanese first, with an English translation immediately below.

日本語

MonoFlick (以下「本アプリ」) は、ユーザーが iPhone から Mac コンパニオンアプリへ片手フリック入力を送信するためのツールです。

1. データを外部に送信しない

本アプリは 外部サーバへいかなる個人データも送信しません。本アプリの開発者が運用するサーバ、解析サービス、広告ネットワーク、クラッシュレポートサービスへの送信経路は存在しません。

2. 端末内に保存する情報

本アプリが取得・保存する情報は、ユーザーの iPhone および Mac の端末内に限定されます。

  • 設定 (Preferences): フリック割り当て、外観、Bluetooth 設定など — iOS / Mac の UserDefaults に保存
  • キーバインド (Keybinds): ユーザーが作成した keybind 定義 — iOS の Documents/keybinds.json
  • ペアリング情報: Mac との通信に用いる共有秘密 — iOS / Mac の Keychain
  • 送受信ログ: 既定で テキスト本文を含まないメタ情報のみ (appLogRedact=true)。診断目的でユーザーが appLogRedact を OFF にした場合、テキスト本文を含むログがローカルの .log ファイルに記録されることがあります。本ファイルは端末外には送信されません

3. 取得しない情報

本アプリは以下の情報を 取得しません。

  • 広告 ID (IDFA) / 端末識別子 (UUID 等の永続識別子)
  • 位置情報
  • 連絡先 / カメラ / マイク / 写真 / ヘルスデータ
  • 解析・クラッシュレポート (Firebase / Sentry / Crashlytics 等のサードパーティ SDK は導入していません)

4. ローカルネットワーク / Bluetooth

ローカルネットワーク (Bonjour 経由の MultipeerConnectivity) および Bluetooth Low Energy は、ユーザー自身の Mac コンパニオンアプリと通信する目的のみ に使用します。広告・解析・端末識別には使用しません。通信内容は ECDH 鍵交換と AEAD (ChaCha20-Poly1305) でエンドツーエンドに暗号化され、Apple の標準 CryptoKit を使用しています。

5. アプリ内課金 (StoreKit)

本アプリは Apple の StoreKit を用いてアプリ内課金を提供します。Apple が処理する 商品 ID と購入時刻 のメタ情報を受け取り、アプリ内 entitlement 判定に使用します。クレジットカード番号・氏名・住所を本アプリの開発者が受け取ることはありません。

6. 子供のプライバシー

本アプリは App Store の年齢レーティングで 4+（全年齢対象） に分類されており、暴力・性的表現・不適切な広告等のコンテンツは含みません。ただし開発者として 13 歳未満のユーザーを直接ターゲットとはしておらず、いかなる年齢層からも個人情報を意図的に収集することはありません。

7. AI 学習目的の利用禁止

本アプリのコード・テキスト・素材を生成 AI モデルの学習用途に使用することを禁じます。本ポリシーおよびアプリ画面に表示される免責文言は MonoFlick 公式に帰属し、商用・非商用を問わず再配布や学習データへの取り込みは認められません。

8. 変更履歴

本ポリシーに変更があった場合は、本ファイルの Git 履歴で公開し、必要に応じてアプリ内 About 画面のリンクから案内します。

ENGLISH

English

MonoFlick is an input tool that lets users type with one hand on iPhone and send keystrokes to a Mac companion app.

1. No external data transmission

MonoFlick does not send any personal data to external servers. There is no developer-operated backend, analytics service, advertising network, or crash reporter receiving any data from the app.

2. Data stored on device

Data MonoFlick collects and stores is limited to the user's iPhone and Mac.

  • Preferences: flick assignments, appearance, Bluetooth settings — stored in UserDefaults on iOS / Mac
  • Keybind definitions: user-authored keybinds — stored in Documents/keybinds.json on iOS
  • Pairing secrets: shared secrets used to talk to the Mac — stored in the Keychain on iOS / Mac
  • Send / receive logs: metadata only, redacted by default (appLogRedact=true). If the user turns appLogRedact off for diagnostics, logs may contain typed text in a local .log file. The file is never sent off-device

3. Information we do not collect

MonoFlick does not collect the following.

  • Advertising identifiers (IDFA) or persistent device identifiers (UUIDs)
  • Location data
  • Contacts, camera, microphone, photos, or health data
  • Analytics or crash reports (no Firebase / Sentry / Crashlytics or similar third-party SDKs are integrated)

4. Local network and Bluetooth

Local networking (MultipeerConnectivity via Bonjour) and Bluetooth Low Energy are used only to communicate with the user's own Mac companion app. They are never used for advertising, analytics, or device tracking. Traffic is end-to-end encrypted using ECDH key exchange and AEAD (ChaCha20-Poly1305) built on Apple's standard CryptoKit.

5. In-app purchases (StoreKit)

MonoFlick uses Apple StoreKit for in-app purchases. The developer only receives the product ID and purchase timestamp metadata that Apple emits, used to determine in-app entitlements. We never receive credit card numbers, names, or addresses.

6. Children's privacy

MonoFlick is rated 4+ (suitable for all ages) in the App Store and contains no objectionable content (violence, sexual content, inappropriate advertising). As the developer we do not directly target users under 13, and we do not intentionally collect personal information from users of any age.

7. Prohibited uses for AI training

Use of MonoFlick's code, text, and assets to train generative AI models is prohibited. This policy and any disclaimer text shown in the app are property of MonoFlick, and may not be redistributed or ingested into training datasets, whether for commercial or non-commercial purposes.

8. Change history

Updates to this policy are versioned in the Git history of this file and surfaced via the in-app About screen link when applicable.
