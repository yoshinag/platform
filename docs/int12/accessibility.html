アクセシビリティ

最終更新日: 2026-04-30

1. 基本方針

「INT12」（以下「本アプリ」）は、年齢や利用環境を問わず、できるだけ多くの方に学習をお楽しみいただけることを目指して開発されています。本ページでは、本アプリで利用可能なアクセシビリティ機能と、現時点での制限事項についてご案内します。

2. 対応している機能

2.1. 表示

機能説明
ダークモード アプリ内の「設定」からライトモード／ダークモードを切り替え可能。OS のシステム設定とは独立してアプリ単位で固定できます。
文字サイズの拡大 iOS / iPadOS の 「設定」→「画面表示と明るさ」→「テキストサイズを変更」、または「アクセシビリティ」→「画面表示とテキストサイズ」→「さらに大きな文字」の設定に追従し、本アプリのテキストもあわせて拡大されます（Dynamic Type 対応）。
太字テキスト iOS の「アクセシビリティ」→「画面表示とテキストサイズ」→「文字を太くする」設定に追従します。
透明度を下げる / コントラストを上げる iOS のシステムアクセシビリティ設定に追従します。

2.2. 操作

機能説明
VoiceOver iOS / iPadOS / macOS 標準の VoiceOver で画面の主要なテキストを読み上げます。問題文・選択肢・ボタンのラベルが順に読み上げられます。
※ 一部のカスタム描画要素では、補助ラベルが十分に整備されていない箇所があります。今後のアップデートで段階的に改善予定です。
スイッチコントロール iOS 標準のスイッチコントロールでアプリ内の主要な操作（解答の選択、画面遷移、ボタンの押下）が可能です。
キーボード操作（iPad / Mac） 外付けキーボード接続時、Tab キーでフォーカス移動、Return キーで決定が可能です。

2.3. モーション

iOS の「アクセシビリティ」→「動作」→「視差効果を減らす（Reduce Motion）」を有効にすると、不要なアニメーションが抑制されます。

3. アクセシビリティを設定する場所

本アプリのアクセシビリティ設定は、デバイスのシステム設定と連動します。詳しい設定方法は以下のリンクをご参照ください。

  • iPhone / iPad: iPhone のアクセシビリティ機能
  • Mac: Mac のアクセシビリティ機能

4. 現時点の制限事項

本アプリは継続して改善中であり、現時点では以下の制限があります。あらかじめご了承ください。

  • すべてのカスタム UI 要素に対する VoiceOver の補助ラベルが完全には整備されていません
  • 音声読み上げ用の独自ナレーション機能は提供していません（OS の VoiceOver をご利用ください）
  • 画像・図版を含む一部のクイズには、代替テキストが付与されていない場合があります
  • 触覚フィードバック（Haptics）の独自実装はありません

5. 音声・動画コンテンツについて

本アプリは音声ナレーションや動画コンテンツを含みません。すべての出題はテキストおよび静止画像で構成されています。そのため、字幕や手話通訳の提供対象となるコンテンツはありません。

6. 学習者への配慮

本アプリは小学校レベルの問題を扱うため、以下の点に配慮しています。

  • 難読語・専門用語にはふりがなを付与
  • 選択肢のタップ領域は十分な大きさを確保
  • 誤答時もネガティブな表現を避け、再挑戦を促す表示
  • 強い点滅や急激な画面変化を伴うアニメーションは使用していません
